# kenhtaymay.github.io

Trang gốc của tài khoản trên GitHub Pages. Chỉ có hai việc:

- `index.html` chuyển tới trang của ứng dụng [Nhắc Tốc Độ](https://kenhtaymay.github.io/nhac-toc-do/).
- `app-ads.txt` (thêm khi có mã nhà xuất bản AdMob) phải nằm ở gốc tên miền này, vì AdMob đọc
  `https://kenhtaymay.github.io/app-ads.txt` theo ô Website trên Google Play.
